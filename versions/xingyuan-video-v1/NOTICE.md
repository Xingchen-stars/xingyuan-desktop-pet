# 参考项目

星渊视频桌宠的透明视频播放与基础交互设计参考了 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。本轮基础交互核查版本：`7f54ef7662ed822e56b6f94574c0ecd7448c4b91`（2026-10-21）。感谢原作者的开源工作。

本版使用星渊自己的角色参考图和用户提供的视频，不包含 dsh-pet 的大肥鱼动画、提示词或源视频。本轮随机动作调度、轻触回弹与位置保存代码针对星渊现有 Electron 程序独立实现，不把 DSH 专用宿主或账号依赖搬入应用。

dsh-pet 的代码许可证为 MIT；其 README 对素材使用与二创署名另有说明，实际引用其源码或素材时需继续遵守对应说明，不能将代码许可直接当成素材许可。
